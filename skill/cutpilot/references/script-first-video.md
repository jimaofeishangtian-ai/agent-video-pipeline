# Script-first and faceless route

Use this route when the source is a script, outline, article, or topic without usable on-camera speech.

## Order of work

1. Extract the argument, proof, examples, transitions, and CTA. Remove repetition before timing visuals.
2. Run the consolidated intake once. Require a narration-source choice and collect only unanswered creative decisions.
3. Produce a narration-ready script with semantic beats. Do not create detailed scene timing against an unapproved or provisional voice unless building an explicitly requested silent prototype.
4. Lock narration and create word/sentence timing. Make it authoritative for captions and scene boundaries.
5. Use video-shotcraft automatically when an installed exact card matches the beat. Use real or licensed evidence before decorative generation.
6. Use Remotion V3 for captions, recurring semantic graphics, evidence, assembly, audio, and the master timeline.
7. Use HyperFrames for the few motion-led scene groups that materially benefit from custom HTML, 3D, diagram, UI, or kinetic design. Review and approve each group before rendering it as a Remotion intermediate.
8. Review the complete piece only in Remotion Studio. Do not render the final before explicit approval.

## Visual density

- Let narration carry nuance; use visuals to clarify relations, proof, transformation, and memory anchors.
- Avoid replacing every sentence with a separate card or generated clip.
- Prefer 2–5 coherent visual chapters over dozens of disconnected effects for a 60–120 second video.
- Return to visual breathing room after dense explanations.

## Narration choices

Offer only callable choices. Explain cost or login requirements before generation. Voice cloning always requires explicit authorization. Preserve the selected voice, pace, pronunciation dictionary, and loudness settings in `narration-manifest.json`.
